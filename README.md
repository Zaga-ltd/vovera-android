# Vovera for Android

Official Android downloads of **Vovera: AI Speaking Coach** by Zaga Group Limited.

This repository holds release files only — no source code.

**Download:** <https://vovera.zaga.social/android/vovera.apk>  
(or try Vovera in your browser at <https://app.vovera.zaga.social>)

| File | For |
| --- | --- |
| `vovera.apk` | Almost every Android phone (64-bit, 2017 and later) |
| `vovera-armeabi-v7a.apk` | Older 32-bit phones |
| `vovera-universal.apk` | Any device (larger download) |

Every APK is signed with the Vovera release key. Certificate SHA-256:
